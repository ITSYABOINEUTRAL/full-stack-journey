# Full Stack Journey

Welcome to my **Full Stack Journey**.

This repository contains my work and practice as I learn full-stack web development. I’m using it to keep track of the things I learn, the exercises I work on, and the projects I build along the way.

The repository is organised by weeks, with each week containing the files and projects I worked on during that part of my learning.

## What I'm Learning

My goal is to build a solid understanding of both the frontend and backend sides of web development.

As I go through the journey, I'll be working with technologies and concepts such as:

* HTML
* CSS
* JavaScript
* Frontend development
* Backend development
* Databases
* APIs
* Authentication
* Git and GitHub
* And other tools and technologies as I progress

## Repository Structure

The work is organised into weekly folders:

```text
full-stack-journey/
│
├── week-1/
├── week-2/
├── week-3/
├── ...
└── README.md
```

The contents of each week will change as I learn new topics and work on new projects, so this repository will continue to grow throughout the journey.

## Why I'm Doing This

I'm using this repository to keep my learning organised and to have a record of my progress.

Instead of only learning concepts and moving on, I want to be able to look back at the code I've written and see how my understanding and projects improve over time.

## Progress

This is a work in progress.

New weeks, exercises, projects, and technologies will be added as I continue learning.
