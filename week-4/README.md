# Week 4

Week 4 continued the JavaScript part of the course by moving into **loops and higher-order array methods**. The exercises were mainly focused on learning different ways to repeat code, work through arrays and objects, and perform operations on collections of data.

The examples in this week are mostly small practice snippets. They are meant to show how each concept works rather than being a single finished project.

## Topics Covered

### Loops

The week introduced different types of loops and how they can be used to repeat an action.

This included:

- `for` loops
- Nested `for` loops
- Looping through arrays
- `break`
- `continue`
- `while` loops
- Nested `while` loops
- `do...while` loops
- `for...of` loops
- `for...in` loops

The examples included looping through numbers, arrays, strings, and arrays containing objects.

### Higher Array Methods

The week also introduced some of JavaScript's higher-order array methods:

- `forEach()`
- `filter()`
- `map()`
- `reduce()`

The exercises used arrays of numbers and arrays of objects to demonstrate how these methods can be used.

For example, `map()` was used to create a new array from existing values, while `reduce()` was used to calculate the sum of the numbers in an array.
